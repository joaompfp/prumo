# Public UI (project 4) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the "Em manutenção" page with a public, server-rendered statistics site where every figure carries its publisher, receipt, verification and licence, and every calculated value is visibly calculated.

**Architecture:** FastAPI + Jinja2 in the existing `app/` package, server-rendered HTML with zero JavaScript. All data access through new read methods on `ingest.db.Db`, opened with `read_db_readonly`. Charts are inline SVG generated in `app/charts.py`. Reader text lives in `presentation/catalog/pt.py`. One CSS file in `static/`. Same `prumo` container; no new service, no migration, no writes.

**Tech Stack:** Python 3.12, FastAPI, Jinja2, SQLite via `ingest.db`, pytest + `httpx` TestClient. No front-end build, no npm, no CDN.

**Spec:** `docs/superpowers/specs/2026-11-15-public-ui-design.md`.

## Global Constraints

- SQL only in `ingest/db.py`; `app/` contains no `sqlite3` import and no SQL string. New queries are `Db` methods with tests.
- The app never writes: only `read_db_readonly`; every route is GET/HEAD (a test asserts it); no POST/PUT/DELETE.
- Numbers render from the stored `value_text` token, never through float, never rounded, scaled or unit-converted. No value is invented, interpolated or aggregated.
- No JavaScript, no external asset, no cookie, no font request. CSP `default-src 'none'; style-src 'self'; img-src 'self' data:; form-action 'self'; base-uri 'none'; frame-ancestors 'none'`.
- Only `role='primary'` series are catalogue entries; cross-check series are shown only on the primary's page; withheld sources are named but never queried for display.
- Reader text only from `presentation.catalog.pt`; a missing key raises. A test walks `registry/core.yaml` and fails if any active, redistributable series lacks family/geography/unit/theme/frequency text.
- Python is `.venv-ci/bin/python`. Tests must not touch the network.
- No merge to `main`, no deploy, no restart of the worker without the owner's explicit instruction. Protected `AGENTS.md`/`CLAUDE.md` untouched.
- Commit messages describe the change truthfully; no co-author or session trailer.

## Review Focus

1. A figure rendered without its source and receipt line -> defect.
2. A derived value rendered with the same styling as a published value -> defect.
3. A withheld source (REN, FRED, OECD, DGEG) appearing in any public list or count -> defect.
4. A cross-check series appearing as a catalogue entry or at its own URL -> defect.
5. Raw codes in visible text (`worldbank_gdp_growth`, `estimated`, `sa_base`) -> defect.
6. HTML/URL injection through source names, attributions, native codes or evidence URLs -> Jinja autoescape on; only `https://` URLs become links.
7. A series with zero or one served value, or a 15-minute series, producing a broken chart -> defect.
8. Both public URLs (root and `/dados` prefix) producing working links and static assets -> defect otherwise.

### Task 2: Public read methods on `Db`

**Files:**
- Modify: `ingest/db.py`
- Test: `tests/ingest/test_db_public_reads.py`

**Interfaces (all read-only, plain dicts, no SQL outside `db.py`):**
- `Db.public_counts() -> dict` -> `series`, `observations`, `sources`, `last_fetched_at` (only redistributable sources and served rows).
- `Db.public_catalogue() -> list[dict]` -> every served `role='primary'` series: `id, indicator_key, family, geography, theme, frequency, unit, multiplier, seasonal_adjustment, base_year, native_code, url, source, latest_period, latest_value_text, latest_status_flag, latest_fetched_at, served_count`.
- `Db.public_series(series_id) -> dict | None` -> the series row (same fields) plus `first_period`, `periods`, `served_count`; `None` if unknown.
- `Db.public_series_values(series_id) -> list[dict]` -> served rows oldest period first: `period, value_text, status_flag, fetched_at, run_id, raw_sha` (use for the chart and the table; cap in `reads.py`, not in SQL).
- `Db.public_provenance(series_id) -> dict | None` -> for the newest served row: `period, value_text, fetched_at, run_id, run_started_at, run_finished_at, raw_url, raw_fetched_at, http_status, sha256, bytes, verification_created_at, sample_size, verification_passed, sample_procedure, verifier_channel, sampled` (bool: a `verification_item` for this series and period in that verification), plus `source_licence, source_licence_url, attribution, native_code, series_url`.
- `Db.public_revisions(series_id) -> tuple[list[dict], int]` -> (periods with more than one version across `state='verified'` runs, newest first, each `{period, versions: [{value_text, fetched_at, run_id, served}]}`; count of periods with exactly one version). Failed, pending and withdrawn runs never appear.
- `Db.public_derived_for_base(series_id) -> list[dict]` -> active derived keys with `base_series_id = series_id`: `key, unit, caveats, latest_period, latest_value_text, formula`.
- `Db.public_derived(key) -> dict | None` -> definition (`key, formula, base_series_id, params, unit, caveats, active`) + `served_count, latest_period, latest_value_text` + base series `id, indicator_key, source`.
- `Db.public_derived_values(key) -> list[dict]` -> served derived rows oldest first: `period, value_text, computed_at, run_id`; `inputs` on the newest row come from `Db.served_derived_rows`.
- `Db.public_cross_checks(series_id) -> list[dict]` -> active `role='cross_check'` series sharing the same `indicator_key`: `id, source, latest_period, latest_value_text, latest_status_flag, attribution`.
- `Db.public_sources() -> list[dict]` -> all sources with `name, licence, licence_url, attribution, redistribution_ok, series, last_fetched_at` (series and last fetch zero/None for withheld sources).

- [ ] **Step 1: Write failing tests** building a small DB with the helpers used by `tests/ingest/test_task20_serving.py` / `tests/ingest/test_db_backoffice_reads.py`: catalogue excludes inactive, cross-check and withheld sources; latest pick honours the served view; provenance carries the receipt and verification and `sampled` is true/false correctly; revisions ignore failed runs and mark the served version; derived rows respect the served view; cross-checks match by indicator key; empty DB returns empty lists and zero counts.
- [ ] **Step 2: Run** -> FAIL.
- [ ] **Step 3: Implement** the methods next to the existing backoffice reads; every one uses the `served_observation` / `served_derived` views, never raw `observation` for served values. Verify the catalogue query measures under 60 ms on a copy of production.
- [ ] **Step 4: Run** the new tests and `tests/ingest/test_db.py` -> PASS. **Step 5: Commit** `feat(db): public read layer for the site`.

### Task 4: Formatting and SVG charts

**Files:**
- Create: `app/formatting.py`, `app/charts.py`
- Test: `tests/app/test_formatting.py`, `tests/app/test_charts.py`

**Interfaces:**
- `format_value(token: str) -> str`: keeps the token's decimals, swaps `.` for `,`, groups thousands with a non-breaking space, preserves a leading minus.
- `format_period(period, frequency) -> str`: `2026` -> `2026`; `2026-Q1` -> `1.º trimestre de 2026`; `2026-S1` -> `1.º semestre de 2026`; `2026-10` -> `Outubro de 2026`; ISO 15-minute -> `13/11/2026, 14:30 UTC`.
- `format_datetime(iso) -> str`: `15/11/2026, 08:49 UTC`.
- `format_date(iso) -> str`: `15/11/2026`.
- `format_count(n) -> str`: grouped integer.
- `line_chart(points, *, frequency, title, width=880, height=340) -> Markup`: inline SVG, hairline axes, 4-6 round y ticks, x labels at most 6, red last point, `<title>` for accessibility, no `<script>`, no `style=`. Handles 1 point (dot only) and negative values.
- `sparkline(points, *, width=132, height=40) -> Markup`: path only, no axes; empty -> empty string.

- [ ] **Step 1: Failing tests** for separators (`1 234 567,89`), decimals preserved (`3.90` -> `3,90`), negative, period labels incl. quarters/semesters/15-minute, datetime; chart has a path with finite coordinates, ticks are round numbers, label is escaped, single point does not divide by zero, negative domain contains zero, no `script`/`style=` in output; sparkline empty-safe.
